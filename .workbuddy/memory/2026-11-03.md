### 应用图标改为完整 Lshell 字标

用户要求打包产物里的图标显示完整 Lshell，不再只取首字母 `L_`。

**做法**：图标改为「L 大字 + shell 小字 + 词尾光标块」的锁定组合（Lockup），
- `scripts/make_icons.py` 重写渲染层：
  - 新增 SVG path 解析器（`M/L/Q/Z`），把 `shell` 的二次贝塞尔曲线离散为折线
    （此前只支持 `M/L/Z`，只能渲染 L 这一个直线轮廓）；
  - 排版：`L_RATIO=2.20` 控制 L 与 shell 的大小比，`PADDING=0.060` 控制安全边距，
    两者共基线，按总宽反算缩放系数 `k_s` / `k_l`；`OPTICAL_LIFT=0.045` 做光学上提。
  - 命中测试：整块墨迹外接矩形先做快速排除，再逐轮廓（带 bbox）做奇偶规则多边形判定。
- **踩坑**：`ls_gap` 是字标单位，却在布局里直接加到像素坐标上 → 整体右移溢出画布，
  光标块被画到画布外（ink bbox 287 > 256）。修正为 `ls_gap * k_s`。
- 参数对比后选定 pad 0.060 / ratio 2.20（比值越大 L 越占、shell 越易糊）。

**产出**：`src-tauri/icons/{16,32,48,128,256}.png` + `icon.ico` 全部为完整 Lshell。
`design/logo.html` 新增 06「应用图标」板块（尺寸阶梯 + 桌面/任务栏模拟），资产清单补图标条目。

**遗留权衡**：16 / 32px 下 5 个字母压缩到 6-7px 高，文字会糊（48px 起清晰可辨）。
若要小尺寸可读，需为 16/32 单独出紧凑版标记 —— 等用户决定。

### 图标改为「主标识原样搬入方形徽标」（推翻上一版锁定组合）

用户反馈：应把主标识的设计原本不动地做成 logo，而不是重新设计一版锁定组合。

**最终方案**（`scripts/make_icons.py`）：
- 徽标底 = 应用深色主题（#12161E → #0A0C10 渐变 + 字标背后靛紫柔光 GLOW=0.22）
- 字标 = wordmark.json 原版轮廓 + 原版配色，**等比缩放、不做任何重排**：
  L 与光标块 #7C8CFF，shell #E6E9F0
- 排版只调「放多大」不改「长什么样」：PAD_BIG=0.070（≥64px）/ PAD_SMALL=0.040（<64px）
- 渲染器支持每个图形带颜色（shapes 元组带 rgb），底色与墨迹分离渲染

**关键认知**：字标宽高比 3.52:1，等比缩进方形徽标后字母高度比锁定组合更充裕 ——
32px 下仍能读出「Lshell」，48px 起清晰。反倒是「大 L + 小 shell」的锁定组合把文字压得更小。

**踩坑**：shapes 元组索引不一致（rect 颜色在第 5 位、poly 在第 3 位）导致 IndexError。

**展示页同步**：`design/logo.html` 06 板块文案改为「主标识原样搬入」，
尺寸阶梯展台从深色改为浅色（深色徽标在深底会融），桌面模拟背景改为石板紫灰渐变。

### 打包后 logo 新鲜度的完整保障（根因修复）

用户诉求：「保证我构建包后，logo 都是最新的」。此前只做了「构建前重生成文件」，
但真机实验证明**exe 里的图标仍可能是旧的** —— 根因在 cargo 层：

**根因**：`tauri-winres` 把 `icon.ico` 编译进 exe 的 Windows 资源段，但它**不声明**
`cargo:rerun-if-changed`；`tauri-build` 只为 `tauri.conf.json` 声明。
Cargo 的规则：build script 一旦输出任意一条 `rerun-if-changed`，就切换为**白名单模式**，
之后只跟踪列出的路径 → 只改图标时 build script 不重跑 → 资源段不重编 → exe 里是旧图标。

**修复 1** `src-tauri/build.rs`：显式为 6 个图标文件输出 `cargo:rerun-if-changed`。
**修复 2** `scripts/gen_assets.mjs`（新）+ `npm run assets`：探测 python（python/python3/py），
  找不到就明确报错终止（绝不跳过生成），生成后校验产物存在 + 内容变化必须落盘，打印 sha256 指纹。
**修复 3** `scripts/verify_icons.mjs`（新）+ `npm run assets:verify`：直接检查 exe 字节流里
  是否含当前 128/256 PNG（ico 内部以 PNG 存图，rc.exe 原样拷贝 → 可精确比对）。
**优化**：两个生成器改为「内容相同则不写」（write_if_changed）—— 否则每次构建 mtime 都变，
  触发 cargo 无谓重编 + 重链（实测多花 ~25s）。副作用：文本产物从 CRLF 规范化为 LF。

**实验证据**（debug 构建，E:/data/Lshell/src-tauri）：
| 场景 | exe 内嵌图标 |
|---|---|
| 只改图标 + 有 build.rs 修复 | ✓ 更新为新图标 |
| 只改图标 + 原始 build.rs | ✗ 仍是旧图标（exe 字节数完全相同，压根没重编） |
| 改图标后未重建 + assets:verify | ✗ 正确报「exe 里是旧图标」 |

**环境要点（重要）**：
- 项目根是 `C:/Users/xcli/WorkBuddy/Lshell`，其中 design/dist/docs/scripts/src/src-tauri/
  node_modules 是指向 `E:/data/Lshell/` 的**符号链接**；package.json 等是 C 盘真实文件。
  → **npm 命令从 C 盘根跑，cargo 从 E 盘真实路径跑**（C 路径下曾报 `.cargo-build-lock` 拒绝访问）。
- Python 里访问 E 盘要用 `E:/data/...`，`/e/data/...` 是 Git Bash 路径，Python 不认。
- 本机无 NSIS/WiX 缓存，`npm run tauri build` 的打包阶段需联网下载 → 未执行完整安装包构建。

## P0 收尾：终端搜索 / 命令历史 / 右键菜单（16:20–17:20）

### 交付内容
1. **终端内搜索**：`@xterm/addon-search` 0.15.0，Ctrl+Shift+F（终端聚焦时），实时高亮 + 匹配计数 + Aa 大小写开关。组件 `TerminalSearch.tsx`。
2. **命令历史**：SQLite 新表 `command_history`（schema v1→v2），前端 `command-capture.ts` 从 onData 字节流还原命令；历史面板 `Ctrl+Shift+H`（跨主机检索 + 一键重放）。Rust 命令 record_command / list_command_history / clear_command_history。
3. **终端右键菜单**：`TerminalContextMenu.tsx`，9 项（复制/粘贴/全选/搜索/命令历史/SFTP 打开当前目录/重连/断开/清屏），按状态禁用 + 视口边界翻转。
4. **ErrorBoundary**：渲染期异常兜底，避免白屏。

### 关键教训
- **`registerDecoration` 是 xterm proposed API**：必须 `new Terminal({ allowProposedApi: true })`，否则搜索高亮抛错 → React 卸载整棵树（白屏）。这是本次最大的坑，靠 `scripts/ui-errors.mjs`（CDP 异常捕获）定位。
- **`@xterm/addon-history` 在 npm 上不存在**（npmmirror 搜索 0 结果 + 404），官方 addon 无 history，命令历史只能自己实现。
- **schema 迁移必须分步**：原 `migrate()` 用 `if version < SCHEMA_VERSION` 一刀切，升 v2 会让 v1 库重跑 v0→v1 的凭据清理（清空用户密码！）。已改为每个版本独立 if 块，并加了 `migrating_from_v1_keeps_existing_secrets` 回归测试。
- **Tauri debug 版嵌入 dist 资源**：改前端后必须 `cargo build` 才生效；WebView2 还会缓存旧 index.html，需清 `%LOCALAPPDATA%/com.lshell.desktop/EBWebView/Default/{Cache,Code Cache}`。
- **命令历史安全**：sudo/su/ssh/mysql 之后的那一行是密码输入（不回显但本地能捕获），捕获器按状态机直接丢弃，绝不入库。UI 实测验证：FakeSecret123 零条入库。

### 设计决策（写进了 README）
- 不劫持 ↑↓ 方向键（远端 readline 拥有），命令召回走历史面板
- 方向键/Tab 补全后的行不记录（本地无法还原远端 readline 的改写）—— 宁可少记不可记错
- `npm test` = `node --experimental-strip-types --test`（Node 22+，无需装 vitest）
