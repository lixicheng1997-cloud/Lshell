03

设计规范摘要

确认方向后，以下规范会作为实现依据；落地时全部写进 src/styles.css 的 :root 变量与组件 class，不引入 UI 框架。

01颜色使用纪律

  • 界面里只允许出现 1 个高饱和色（靛紫）。它只用于：当前选中项、聚焦描边、主按钮、终端光标。
  • 绿 / 黄 / 红 仅表示连接状态，绝不用作装饰，否则状态语义被稀释。
  • 所有描边用 --line 及以上层级，禁止纯黑描边——纯黑会让界面显得生硬廉价。
  • 状态点统一 6px + 同色 14% 光晕环，一眼可辨四种状态。

02圆角与间距

--r-sm 6px小图标按钮、输入框、列表行
--r-md 9px按钮、搜索框、标签页
--r-lg 14px对话框、浮层
--r-xl 18px窗口外框、卡片容器
间距基数 4px常用 8 / 12 / 14 / 16 / 20 / 24

03排版

  • 界面字体：Segoe UI Variable → Microsoft YaHei UI → 系统中文字体，与 Windows 原生观感一致。
  • 终端字体：Cascadia Code → Consolas，行高 1.72（旧版偏挤，长日志难读）。
  • 字号：正文 13 / 列表 12.5 / 辅助 11.5 / 分组标题 10.5（字重 700 + 字距 .12em）。
  • 数字与地址一律用等宽字体（mono），保证列对齐。

04相较现状的关键改动

  • 分离标题栏与顶栏：标题栏只放品牌与窗口控件，顶栏只放功能。旧版挤在 44px 一行内，是「网页感」的根源。
  • 标签页改为圆角浮片：旧版是带右边框的传统标签页，像 2010 年的 IDE。
  • 去掉米黄底色：#f7f7f6/#f1efe8 换成冷调灰，界面更「干净中性」。
  • 新增深色为默认：终端类工具深色是刚需，深色也更能凸显靛紫主色。
  • 图标全部内联 SVG（1.6px 描边），不依赖任何图标字体或 emoji。
  • 主按钮带辉光：0 4px 14px -6px 靛紫投影，是「引人入胜」的关键一笔，成本极低。

  • 新增 styles/tokens.css 与 styles/components.css，拆分变量与组件，便于维护。

B组件层

  • 拆分 App.tsx 的顶栏 / 标题栏 / 状态栏为独立组件。
  • 改造 Sidebar、SftpPanel、HostDialog、VaultGate、HostKeyDialog、ForwardPanel、ShortcutHelp。
  • 新增 Icon.tsx 内联图标集，替换现有 ×、▸、▾ 字符图标。

  • 标签页改为可拖拽排序，连接状态点加呼吸动画。
